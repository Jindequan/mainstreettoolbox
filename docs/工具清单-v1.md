# Main Street Toolbox — 工具清单 v1

> 全站工具目录与建设顺序。入选有标准、每工具有证据、引擎可复用。
> SERP 验证日期 2026-09-05。v1

---

## 1. 入选标准（五条全过才上）

1. **真实任务**：解决一个"今天就要算"的活（报价/发薪/定价/分账），不是"了解一下"
2. **搜索证据**：存在 calculator / generator / template 类长尾词，KD 低或 SERP 由弱小站/营销页构成
3. **计算可拥有**：内置行业基准数据与诊断——这是 AI 口头回答给不了、文章页替代不了的
4. **变现挂钩**：能自然通向 affiliate（POS/payroll/field-service 软件）或 Pro 功能（保存/客户档案/导出）
5. **引擎复用**：计算内核可换行业参数复用（见 §3）

## 2. SERP 验证结论（2026-09-05 实测）

| 发现 | 影响 |
|---|---|
| **field-service SaaS 已把"免费计算器"做成标配获客页**：Jobber、Connecteam、ZenMaid、MyQuoteIQ 等在 cleaning/lawn 报价词上密集成排，且多为留邮箱门控的 lead-gen | cleaning/lawn 报价工具**可打但有争夺**。差异化三板斧：①不门控（无邮箱/注册，即时出结果）②可打印报价单 ③中立品牌（我们不是要卖你 SaaS）。这三点恰好全是 SaaS 页做不到的 |
| **salon booth rent vs commission 是真空**：SERP 只有 GenBook 一篇博客计算器和 Etsy 卖的 Excel 表 | 美业优先级上调，booth rent 计算器是全清单竞争最弱的 P0 |
| **建材计算器被零售商占有**：Home Depot、Decks.com、Trex、Omni 垄断 deck/paint 类，且计算器通向购物 | 不做 DIY 材料计算器正面战；改切**承包商视角**（材料+工时+利润率→投标价），零售商不做的半场 |

## 3. 四个计算引擎（核心资产）

40+ 工具页由 4 个内核驱动，每个内核换行业参数+基准+文案即成新工具——**参数化复用，不是模板换词**（3 月核心更新安全线以内）：

| 引擎 | 逻辑 | 覆盖工具 |
|---|---|---|
| **E1 Quote/Estimate** | 维度（面积/房间/服务行项）× 单价/工时 + 区域系数 → 报价区间 + 可打印报价单 | cleaning ×4、lawn ×4、handyman quote、salon price list |
| **E2 Price/Cost** | 成本 → 目标毛利 → 建议价（心理定价）+ 基准标尺 + 诊断 | 餐饮 5 个、salon pricing、retail markup、通用 break-even |
| **E3 Materials+Bid** | 尺寸 → 材料量(+waste%) + 工时 + 利润率 → 承包商投标价 | deck/paint/tile/drywall/concrete bid |
| **E4 Split** | 总额 → 按比例/人头/规则分账 + 每人明细表 | tip out、booth vs commission、consignment split |

## 5. 明确不做（附理由）

| 不做 | 理由 |
|---|---|
| paycheck calculator（37.8万/月 KD 72） | ADP/SmartAsset 垄断，州税法维护成本极高 |
| invoice generator / invoice template 裸词（KD 63/43） | 只做 "{行业} invoice" 长尾矩阵 |
| menu maker、PPT/设计类 | Canva/Gamma 红海 |
| AI 文案/内容生成器 | ChatGPT 直接替代 |
| 依赖实时 API 的（运费/汇率/报税） | 纯静态架构红线，且数据责任重 |
| DIY 材料计算器正面（deck material calculator 裸词） | Home Depot/Decks.com 占有；只切承包商 bid 视角 |

## 6. 建设波次（映射里程碑）

| Wave | 内容 | 引擎 | 数量 |
|---|---|---|---|
| W1（M1） | 餐饮 | E2+E4 | 10 |
| W2（M2-M3） | Cleaning + Lawn | E1 | 8 |
| W3（M4-M5） | Construction + Salon | E3+E4+E2 | 10 |
| W4（M6） | Retail + Universal | E2+E4 | 8 |

**合计 ~36 个 P0/P1**。每个工具上线清单不变：真实计算逻辑 + 内置基准 + 人话诊断 + 1 篇 guide + FAQ schema。

**波次依据**：W2 选 cleaning+lawn 因为 E1 引擎复用度最高（一次开发四个行业吃）、Pro 客户档案闭环最强、且 affiliate 池最深（Jobber/Homebase/Gusto 都付 $80-300/单）；salon 提前是因为 booth rent 竞争真空，捡漏优先。
