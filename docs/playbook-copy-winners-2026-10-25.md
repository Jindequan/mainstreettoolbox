# 作战手册:抄赢家(2026-10-25 用户令「你去抄」)

原则:不再自创打法。以下每条都是已验证的成功案例 + 我们的可抄路径。

## 抄谁 + 抄什么

### 1. InchCalculator — 同品类直接抄(最优先)
- **证据**:同品类(家装计算器),5.21M 月访问,1.2 万条外链,Gizmodo/Lifehacker 级编辑引用(semrush/creativewidgets 口径)。
- **它的打法**:实用工具被编辑当"参考工具"引用;每个计算器页=大 FAQ+worked example+数据表+首屏工具。
- **我们抄**:①页面形态已对齐(FAQ/worked example 都做了);②缺的是"被引用"通道——用下面 2/3/4 补。

### 2. HARO 继任平台 — 把"我求编辑"反转成"编辑找我"(每周主投)
- **证据**:HARO 死后继任者活跃(Qwoted 免费档/Featured.com/Source of Sources/Help a B2B Writer,2026-10 复核存在)。
- **它们的用户是谁**:天天写 "how much does X cost" 文章的记者/内容编辑,主动发选题找数据源——**正是压着我们的那批 SERP 的作者**。
- **我们抄**:注册 3 平台(需邮箱验证),每天答 cost/home-improvement/contractor 类 query 3 条:报价=我们 50 工种双源基准表,署名带工具链接。行业命中率:答 10-20 条中 1-3,中的是 DR50-90 出版物。**这是引用域判据 0→3 最快的路。**

### 3. .edu Extension 资源页 — 高权重外链直投
- **证据**:各州 extension 本身就运营计算器/资源页(USU 灌溉计算器、UC ANR、CSU、OSU、Texas A&M WaterMyYard、WSU、Purdue、Penn State microgreens 计算器——2026-10-25 实查)。
- **我们抄**:找 10 个州的 lawn/home-maintenance/家庭预算 resource 页,pitch 当地 extension agent 把我们的工具列入资源页(他们本来就在做"给 homeowner 推工具")。首投 10 封,文案钩子=本州数据+免费+无注册。

### 4. Embed Widget — calculator.net 的真实起量打法(产品位,本周上线)
- **它的打法**:计算器被全网上千个站嵌入,每个嵌入=一条外链+引荐流量。
- **我们抄**:给计算器加 `/embed` 轻量版+页脚"Embed this calculator"一行代码框(带署名链接)。投放对象=贸易博客/协会会刊/承包商个人站。把"求外链"变成"送工具换外链"。

### 5. 独立开发者实证(dev.to:14 个计算器 12→150 访客/天/3 个月)
- 证明 calculator-SEO 打法 2026 仍成立,但纯等 SEO 太慢——必须叠加 2/3/4 的分发。
