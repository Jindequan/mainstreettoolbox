# Main Street Toolbox — 前端规范 v1

> 本文件是本站所有页面的**样式契约**。任何新页面/新组件必须复用本文档的 tokens 与组件，不得私自引入新颜色、新字号、新圆角。
> 配套 demo：`web/mainstreettoolbox.com/demo/`（index.html = 营销面，menu-pricing-calculator.html = 工具面）。
> demo/styles.css 即生产设计系统的种子文件。v1 · 2026-09-05

---

## 1. 艺术方向：Main Street Ledger（老店账本）

**一句话**：像一家靠谱老店的收据本——暖纸底、墨绿主色、衬线大标题、发丝分隔线。

**为什么不是别的**：禁用"白底+蓝紫渐变+Inter 全站"的 AI 默认风；不做 fintech 冷感；不做插画风童趣。目标用户 40-55 岁美国小商户，要的是**可信、清楚、像纸**。

**三个品牌记号**（全站仅此三处出现条纹元素，克制使用）：
1. 页顶 6px 招牌条纹（绿/米/橙）
2. logo 方块（同款条纹）
3. 结果卡顶部 4px 绿色压边

## 2. Design Tokens（与 styles.css `:root` 一一对应）

### 2.1 颜色

| Token | 值 | 用途 |
|---|---|---|
| `--paper` | `#FAF7F0` | 页面底色（**禁止纯白 #FFF 做页面底**） |
| `--paper-2` | `#F3EEE2` | 交替区块底 |
| `--card` | `#FFFDF8` | 卡片底 |
| `--ink` | `#26231B` | 正文 |
| `--ink-2 / --ink-3` | `#6E6553 / #9A9078` | 次级/弱文字 |
| `--line / --line-2` | `#E8E1D0 / #D9D0BB` | 发丝线/深线 |
| `--green / --green-2` | `#1E5B3E / #164931` | 主色：按钮、链接、强调（hover 加深） |
| `--green-tint` | `#E5EDE3` | 绿淡底（成功态、聚焦光晕） |
| `--amber` | `#B45309` | eyebrow、排名数字、强调（**不做按钮**） |
| `--ok / --warn / --bad` | `#1A7F4B / #B54708 / #B42318` | 诊断三态，必须配各自的 `-tint` 底色 |

规则：一屏内主绿只出现在"最重要的一个动作 + 链接"上；状态色只用于诊断，不做装饰。

### 2.2 字体

| 用途 | 字体 | 规格 |
|---|---|---|
| 标题/大数字 | **Fraunces**（wght 640，可斜体） | `letter-spacing: -0.015em`；H1 斜体 em 用主绿 |
| 正文/控件 | **Inter**（400/500/600） | 正文 15px 起步（用户年龄偏高） |
| 结果大数字 | Fraunces 3.4rem + `tabular-nums` | 实时更新不跳宽 |

字号阶（只用这几档）：`12 / 13 / 15 / 17 / 22.4 / 32 / 54.4px`（即 --fs-400…--fs-900）。

### 2.3 形状与阴影

- 圆角：小 10px（按钮/输入框）、中 14px（卡片）、大 20px（特殊）
- 阴影只有两档：`--shadow-1`（静态卡）、`--shadow-2`（悬浮/结果卡）；hover 才升级
- 分隔用**发丝线**和**虚线**（dashed 用于"可撕"的收据隐喻：动作条上方、高级选项上方）

## 4. 页面装配规则

1. **工具页黄金分区**：桌面 1.35fr 输入 + 1fr sticky 结果卡（`top:20px`）；移动端垂直堆叠 + **sticky 底部结果条**（64px，大数字+Details 按钮），`body` 加 `padding-bottom: 84px` 防遮挡。
2. **Above the fold 必须能干活**：H1+副标题 ≤120px 高度内结束，输入区和结果卡首屏可见。
3. **中心阅读栏**：below-the-fold 说明文/FAQ 用 `max-width: 46rem` 居中列。
4. **容器**：`--container: 1120px`，左右 padding 24px。⚠️ 教训：给 `.container` 元素写 padding 简写会覆盖左右内边距（demo 的 `.tool-head` 踩过），一律用 `padding-block`。
5. **响应式断点**：860px（双栏→单栏、导航折叠）、540px（单列卡、动作条 2×2）。
6. **打印**：`@media print` 隐藏导航/表单/动作条/页脚，只留品牌头+参数+结果——这是产品功能（Dana 的客户报价单），不是附加品。

## 5. 红线（Do NOT）

1. ❌ 纯白页面底、蓝紫色系、渐变按钮、emoji 图标（用内联 SVG stroke 图标）
2. ❌ 弹窗/alert/cookie 横幅（分析用 cookieless 方案）
3. ❌ 提交按钮等待模式（必须实时计算）
4. ❌ 界面文案出现未解释的行话（contribution margin ❌ → "what you actually keep" ✓）；文案必须中性正规，禁止把内部设计要求写进用户可见文案
5. ❌ 新颜色/新字号/新圆角——先改 tokens 和本文档，再写页面
6. ❌ 触控目标 <44px；正文 <15px
7. ❌ 广告位（AdSense 解除限制前，全站禁止接入任何广告代码）
