# Link Building Playbook — 友好外链建设（2026-09-14）

> 原则：外链是**关系的副产品**，不是请求的结果。我们只做"值得被链接的页面 + 让对的人看见它"。
> 永不：群发、买链、伪装 guest post、在无关评论区撒链接。

## 资产盘点：什么页面值得被链（磁石页）

1. **各行业定价基准 guide**（house-cleaning-prices / food-cost / booth-rent / post-construction）——有数字、有表、有出处，是写文章的人会引用的形态
2. **即将做的枢纽页**：《Service Business Pricing Benchmarks 2026》单页（把四篇 guide 的基准表汇总成一张可引用大表，每行标来源）——**外链磁石一号**，写作优先级提升
3. 免费工具本体（invoice generator / checklist generator 等"替代付费软件"的页面）

## 五条路径（按优先级）

### 路径 1：行业编辑/机构资源页 pitch（已在循环）
- 对象：Cleanfax、Lawn & Landscape、Modern Salon 编辑；SCORE/SBDC 资源页维护人
- 友好要点：引用对方近期具体文章；给"读者价值"而不是"给我链接"；附截图；一次跟进后不再追
- 模板：distribution-kit.md §6

### 路径 2：工具/资源目录提交（本周可做，纯执行）
- 免费工具目录、SMB 资源站、alternativeto 类。逐个确认"接受免费工具提交 + 有真实流量"再提交，宁缺毋滥
- GA 里 dataindex.pro 的 referral 说明目录站会自动收录并带来真实会话——值得系统化

**目录验收清单（2026-09-14 LaunchKiwi 教训，全部通过才提交）：**
1. 首页能直接看到真实 listing 内容和社区活动（产品数/投票/评论非零）——空壳站 0 内容 = 一票否决
2. 不以"dofollow/DR 分数"为核心卖点——卖链接的域会被降权，链了归零还可能牵连
3. 不要求在站点放 badge/回链（放 "Featured on X" 徽章 = 互惠链接模式，Google link scheme 条款明确覆盖）
4. 自报流量/DR 数字一律视为营销话术，找到独立佐证才算数
- 案例：LaunchKiwi "DR 51 dofollow 换 badge" 邀请 → 核实为 0 内容空壳 → 拒绝归档（2026-09-14）

### 路径 3：关系网络（Neal 模式）
- **Neal（Can We Launch）是第一个活例子**：他审计我们 → 我们专业回应+快速修复 → 他主动提出改后重扫。这类站长/工具圈的人**本身就是内容作者**，处理好一次互动 = 未来文章/推文里的自然提及
- 动作：修复上线后回信请他重扫（他已主动提出）；保持轻联系（他 blog 有 launch 相关内容时提供我们的案例数据）

### 路径 4：基准数据引用（磁石页上线后启动）
- 找"write for us"/行业周报，以"我们整理了 2026 服务定价基准"为引子提供数据（不是要链接）
- 监控谁在引用旧数据（如 2024 cleaning price 文章），礼貌提醒有新版

### 路径 5：Broken link building（月度轻量）
- 找清洁/餐饮/美发行业资源页的失效链接（免费 invoice template / pricing guide 类），一封两行信："这个链接挂了，我们有个免费的同类工具，要不要换上"——对站长是帮忙，不是推销

## 记录与纪律

- 每次外联记 marketing-log.md（对象/内容/结果）
- 被拒或无回复 = 停，一次跟进为限
- 拒绝：付费链接、链接农场、无关目录——脏链比没链更伤
